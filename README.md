# Hash Perubahan Data

Proyek ini adalah aplikasi Python sederhana untuk mengecek hash (MD5) dari data profil.

## Cara Penggunaan
1. Pastikan Python sudah terinstall.
2. Jalankan file `cekprofil.py`.
3. Masukkan data yang ingin dicek.

## File dalam Repositori
- `cekprofil.py`: Script utama program.
- `.gitignore`: File untuk mengabaikan file yang tidak perlu diupload.
